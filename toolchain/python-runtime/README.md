# Portable Python graphics runtime

The build tool uses frozen, versioned Python environments for Linux x86_64
and Windows x86_64. **No system Python or `pip` is required** to use the
builder. `build.sh` (Linux) / `build.bat` (Windows) restores the corresponding
runtime from the offline, SHA-256-verified archives in `bundles/`.

The unpacked `linux-amd64/` and `windows-amd64/` folders are generated by the
bootstrap and excluded from Git. Do not commit extracted interpreter files.

The game's text and graphics tool sources are versioned in
`toolchain/python-src/`, and Switch graphics tools in `toolchain/switch_port/`.
The separate `assemble_offline.py` is only a low-level archive assembly tool;
it is **not** run by the ordinary build process.
